# SUMUKHA Frontend Project

## Files
- `index.html` — website structure and sections
- `styles.css` — responsive design and animations
- `app.js` — mobile navigation, reveal effects, local photo preview, demo chat, and account dialog
- `assets/sumukha-logo.png` — put your face-and-leaf logo image here

## Run
1. Extract this ZIP.
2. Open the `SUMUKHA_frontend_project` folder in VS Code.
3. Open `index.html` with the VS Code Live Server extension.
4. Internet access is needed for Google Fonts and the remote portrait images.

## Important
This is frontend-only. Photo preview stays in the browser; the scan button does not perform AI analysis. Chat replies are demo text. Login and registration are only a user interface and do not save or transmit credentials. Python/FastAPI, PostgreSQL, real AI integration, secure authentication, and persistent scan history still need to be built.

Keep face images private, request consent before uploading, and provide a way for users to delete stored images and history.
